# 公式说明文档

> 本文档记录低碳水营养策略中涉及的核心公式。
> ⚠️ 注意：以下公式为营养学通用公式，如有出入请以原书为准。

## 一、BMI（体质指数）

```
BMI = 体重(kg) ÷ 身高(m)²
```

| BMI范围 | 分类 |
|---------|------|
| < 18.5 | 偏瘦 |
| 18.5 ~ 23.9 | 正常 |
| 24 ~ 27.9 | 超重 |
| ≥ 28 | 肥胖 |

> 中国标准与WHO标准略有不同，以上为中国成人BMI标准。

## 二、BMR（基础代谢率）

### 当前使用：Mifflin-St Jeor公式（1990）

```
男: BMR = 10×体重(kg) + 6.25×身高(cm) - 5×年龄 + 5
女: BMR = 10×体重(kg) + 6.25×身高(cm) - 5×年龄 - 161
```

### 其他公式（参考）

**Schofield公式（1985）**
```
男18-30岁: BMR = 15.3×体重(kg) + 679
男30-60岁: BMR = 11.6×体重(kg) + 879
女18-30岁: BMR = 14.7×体重(kg) + 496
女30-60岁: BMR = 8.7×体重(kg) + 879
```

**Harris-Benedict公式（1919，已过时）**
```
男: BMR = 66.5 + 13.75×体重(kg) + 5.003×身高(cm) - 6.755×年龄
女: BMR = 655.1 + 9.563×体重(kg) + 1.850×身高(cm) - 4.676×年龄
```

## 三、TDEE（每日总消耗）

```
TDEE = BMR × 活动系数
```

### 活动系数表

| 活动水平 | 描述 | 系数 |
|---------|------|------|
| 久坐 | 办公室工作，几乎不运动 | 1.2 |
| 轻度 | 每周1-3天轻度运动 | 1.375 |
| 中度 | 每周3-5天中等运动 | 1.55 |
| 重度 | 每周6-7天高强度运动 | 1.725 |
| 极重 | 体力劳动者或运动员 | 1.9 |

### 目标调整

| 健康目标 | 调整系数 |
|---------|---------|
| 减重 | × 0.85 |
| 维持 | × 1.0 |
| 增重 | × 1.10 |
| 糖尿病管理 | × 0.90 |
| 高血脂管理 | × 0.85 |

## 四、三大营养素配比（低碳水饮食）

### 当前实现

| 饮食类型 | 蛋白质 | 脂肪 | 碳水 |
|---------|--------|------|------|
| 温和型 | 25% | 45% | 30% |
| 控制型 | 30% | 50% | 20% |
| 生酮型 | 25% | 70% | 5% |

### 能量换算系数

| 营养素 | kcal/g |
|--------|--------|
| 蛋白质 | 4 |
| 碳水 | 4 |
| 脂肪 | 9 |
| 酒精 | 7 |
