# 「今天，吃了吗？」分餐建议系统设计文档

## 一、功能概述

根据用户每日营养目标（蛋白质/碳水/脂肪克数），按四餐（早/午/加餐/晚）比例拆分，**参考《中国居民膳食指南2022》的食物类别搭配方式**，动态生成每餐具体的"吃什么、吃多少"的餐次建议表。

要求：
- 每天的食物种类有一定变化（不重复）
- 根据档位（控制型/温和型/生酮型）调整搭配
- **加餐放在午餐和晚餐之间**，作为过渡
- 考虑到用户一顿吃不了太多，食物量合理分配

---

## 二、与膳食指南的差异说明

膳食指南2022的食谱是**普通饮食**（碳水50~60%，脂肪24~30%），而我们是**低碳水饮食**：

| | 膳食指南普通比例 | 控制型 | 温和型 | 生酮型 |
|--|:---------------:|:------:|:------:|:------:|
| 碳水 | 50~60% | 35% | 20% | 10% |
| 脂肪 | 24~30% | 50% | 65% | 70% |
| 蛋白 | 10~15% | 15% | 15% | 20% |

**我们的策略**：参考膳食指南的**食物类别搭配方式**（每餐谷薯/肉蛋/蔬菜怎么搭），但**营养素比例按我们的低碳水档位来算**。

## 三、核心算法

### Step 1：每日总量 → 分餐

```
每日总量（夏萌法TDEE × 档位配比）
  ↓
分餐比例：
  早餐：总量 × 25%
  午餐：总量 × 35%
  加餐：总量 × 10%（午餐和晚餐之间的过渡）
  晚餐：总量 × 30%
```

### Step 2：食物类别体系（参考膳食指南2022）

沿用膳食指南的5大食物类别体系：

| 类别 | 每餐定位 | 典型食物 |
|------|---------|---------|
| **谷薯类**（主食） | 碳水主要来源 | 米饭、燕麦、红薯、玉米、荞麦 |
| **鱼禽畜肉蛋类** | 蛋白质主要来源 | 鸡胸肉、瘦肉、鱼、虾、鸡蛋 |
| **蔬菜水果类** | 维生素/纤维 | 叶菜、瓜果、十字花科蔬菜 |
| **乳制品/大豆/坚果** | 蛋白质+脂肪 | 牛奶、豆腐、豆浆、坚果 |
| **烹调油** | 脂肪补充 | 植物油（固定量） |

### Step 3：每餐食物模板（膳食指南风格）

#### 🌅 早餐（25%）— 类似膳食指南例1/2的早餐结构

| 食物项 | 份量说明 | 依据 |
|-------|---------|------|
| 主食（全麦面包/燕麦/红薯） | 该餐碳水的 ~60% | 参考膳食指南：燕麦30g+全麦50g |
| 鸡蛋 | 2个（100g） | 固定，高蛋白供能 |
| 牛奶/酸奶/豆浆 | 1杯（200ml） | 固定，钙+蛋白来源 |
| 蔬菜（黄瓜/番茄/生菜） | 50~100g | 参考膳食指南：凉拌黄瓜50g |

#### ☀️ 午餐（35%）— 一天中最饱的一餐

| 食物项 | 份量说明 | 依据 |
|-------|---------|------|
| 主食（杂粮饭/荞麦面/米饭） | 该餐碳水的 ~70% | 参考膳食指南：米饭70g+小米30g |
| 蛋白质（瘦肉/鸡胸/鱼/牛肉） | 该餐蛋白的 ~70% | 参考膳食指南：鸡腿60~75g |
| 蔬菜（2种随机搭配） | 200g（每种100g） | 参考膳食指南：菠菜200g |
| 植物油 | 10g | 固定炒菜用油 |

#### 🍪 加餐（10%）— 午餐和晚餐之间的过渡

| 食物项 | 份量说明 | 依据 |
|-------|---------|------|
| 水果 | 1份（~200g） | 参考膳食指南：苹果/橙子150~200g |
| 坚果 | 10~15g | 参考膳食指南：坚果10g |

- 定位：不是正餐，是过渡，防止饥饿导致的暴食
- 不占主餐的营养额度，单独从总量中划出

#### 🌙 晚餐（30%）— 碳水最少的一餐

| 食物项 | 份量说明 | 依据 |
|-------|---------|------|
| 主食（粗粮/南瓜/山药） | 该餐碳水的 ~40-50%（最少） | 参考膳食指南：馒头50g |
| 蛋白质（鱼/豆腐/虾） | 该餐蛋白的 ~60% | 参考膳食指南：鱼50g+香干30g |
| 蔬菜（1~2种） | 150~200g | 参考膳食指南：芹菜150g |
| 植物油 | 8~10g | 适量 |

### Step 4：份量计算（"先固定 + 后补齐"法）

以膳食指南1800kcal例子的营养素推算来理解算法：

```
假设用户目标（以某种档位算出）：
  每日：蛋白76g / 碳水247g / 脂肪61g / 总热量 ~1800kcal

分餐：
  早餐25%：蛋白19g / 碳水62g / 脂肪15g
  午餐35%：蛋白27g / 碳水86g / 脂肪21g
  加餐10%：蛋白8g  / 碳水25g / 脂肪6g
  晚餐30%：蛋白22g / 碳水74g / 脂肪19g

早餐的计算过程：
  ① 固定类：鸡蛋2个(100g) → 蛋白13g + 碳水2g + 脂肪9g
              牛奶1杯(200ml) → 蛋白6g + 碳水7g + 脂肪6g
              固定小计 → 蛋白19g + 碳水9g + 脂肪15g
  
  ② 还差：蛋白≈0g + 碳水53g + 脂肪≈0g ← 基本达标！
  
  ③ 主食补齐：选今日主食（比如全麦面包每100g=蛋白8g+碳水46g+脂肪3g）
     要凑53g碳水 → 需要面包 53÷46×100 = 115g ≈ 3片
  
  ④ 结果：鸡蛋2个 + 牛奶1杯 + 全麦面包115g
```

### Step 5：档位特殊处理

| 档位 | 三餐调整 | 加餐调整 |
|------|---------|---------|
| **控制型**（碳水35%） | 早餐/午餐可以吃中等碳水主食，晚餐主食减量 | 水果正常吃 |
| **温和型**（碳水20%） | 早餐少量碳水主食，午餐适量，晚餐基本无主食 | 水果减半或选低GI |
| **生酮型**（碳水10%） | 三餐基本无主食，碳水全部来自蔬菜 | 取消水果，仅保留坚果 |

### Step 6：每天轮换（7天周期）

按日期作为种子，每天从各食物类别的可选池中选不同食物：

```
早餐谷物轮换：
  周一全麦面包 → 周二燕麦 → 周三红薯 → 周四玉米 → 周五荞麦馒头 → 周六山药 → 周日全麦面包

午餐蛋白质轮换：
  周一鸡胸肉 → 周二牛肉 → 周三鱼 → 周四瘦肉 → 周五虾 → 周六鸡腿肉 → 周日豆腐

蔬菜轮换（每天从池中随机选2种）：
  菠菜、油菜、西蓝花、番茄、芹菜、生菜、白菜、茄子
```

## 四、GI（升糖指数）优选逻辑 — 已定

### 分级标准
| 等级 | GI值 | 周频次 | 选餐原则 |
|------|------|--------|---------|
| 🟢 低 | < 55 | 22~24次 | 日常主力 |
| 🟡 中 | 55~70 | 3~4次 | 偶尔换口味 |
| 🔴 高 | > 70 | 1~2次 | 尽量安排在午餐 |

### 使用规则
```
每餐选碳水食物时：
  ① 查"本周已用GI配额"
  ② 低GI池还有配额 → 必须优先选低GI
  ③ 中GI/高GI还有余量 → 可偶尔换口味
  ④ 高GI尽量放在午餐（下午活动多，血糖波动影响小）
```

## 六、开发计划（分期）

### 第一期（MVP）
- 食物模板硬编码在JS里
- 按分餐比例生成每日建议表
- 7天固定轮换
- 用户可勾选吃了/没吃
- 展示每日偏差

### 第二期
- 食物模板放到Supabase管理
- 用户可输入实际克数
- 周累计统计
- 自动调整建议（前3天吃多了→后4天建议少吃）

### 第三期
- 图表展示趋势
- 用户自定义食物选项
- 个性化推荐优化

## 七、已确认事项

| 事项 | 结论 |
|------|------|
| 分餐比例 | 早餐25% / 午餐35% / 加餐10% / 晚餐30% |
| 加餐位置 | 午餐和晚餐之间（过渡） |
| GI频次 | 低22~24次/中3~4次/高1~2次（按周28餐次） |
| 食物分类 | 参考膳食指南5大类：谷薯/肉蛋/蔬菜水果/乳豆坚果/油脂 |
| 营养素计算 | 先算营养素目标（夏萌低碳水配比），再转成食物，膳食指南仅参考搭配方式 |
| 早餐蛋白组合 | 固定鸡蛋+奶制品为主，偶尔可换（如全蛋饼+豆浆） |
| 蔬菜安排 | 早餐配少量蔬菜（50~100g），午餐晚餐各200g蔬菜（可选1~2种），加餐无蔬菜（只有水果） |
| 用户主动选食物 | 目前系统无此入口，全部自动推荐，后续再加 |
| 周末安排 | 7天统一轮换，周末最多1天可提供不同食谱（换换口味） |
