# 🥗 低碳水营养计算器

基于GX低碳水营养策略的在线营养计算工具。

## 功能特点

- 📊 **BMI & 基础代谢计算** - Mifflin-St Jeor公式
- 🎯 **多用户独立管理** - 支持4个用户，数据互不干扰
- 🔗 **URL分享功能** - 每人一个独立链接，参数加密在URL中
- 🍽️ **食物换算** - 将营养目标换算为每日具体食物建议
- ⚡ **三种低碳水强度** - 温和型 / 控制型 / 生酮型

## 公式说明

### BMR（基础代谢率）- Mifflin-St Jeor公式

```
男: BMR = 10×体重(kg) + 6.25×身高(cm) - 5×年龄 + 5
女: BMR = 10×体重(kg) + 6.25×身高(cm) - 5×年龄 - 161
```

### TDEE（每日总消耗）

```
TDEE = BMR × 活动系数 × 目标调整
```

活动系数：
| 活动水平 | 系数 |
|---------|------|
| 久坐 | 1.2 |
| 轻度 | 1.375 |
| 中度 | 1.55 |
| 重度 | 1.725 |
| 极重 | 1.9 |

目标调整：
| 目标 | 系数 |
|------|------|
| 减重 | 0.85 |
| 维持 | 1.0 |
| 增重 | 1.10 |
| 糖尿病管理 | 0.90 |
| 高血脂管理 | 0.85 |

### 低碳水营养素配比

| 类型 | 蛋白质 | 脂肪 | 碳水 |
|------|--------|------|------|
| 温和型 | 25% | 45% | 30% |
| 控制型 | 30% | 50% | 20% |
| 生酮型 | 25% | 70% | 5% |

### 能量换算

- 蛋白质：4 kcal/g
- 碳水：4 kcal/g
- 脂肪：9 kcal/g

## 使用方法

1. 直接打开 `index.html` 即可使用
2. 输入个人信息，点击"计算我的营养方案"
3. 切换顶部标签可管理不同家庭成员的数据
4. 点击"分享此方案"生成分享链接

## GitHub Pages 部署

1. Fork 本仓库
2. 在仓库设置中启用 GitHub Pages
3. 选择 `main` 分支和 `/ (root)` 根目录
4. 访问 `https://你的用户名.github.io/nutrition-manager/`

## 注意事项

⚠️ 本工具仅供参考，不构成医疗建议。
- 慢性病患者（糖尿病、高血压等）请在医生指导下进行饮食调整
- 生酮饮食需要在专业营养师指导下进行
- 60岁以上人群执行低碳水饮食需格外注意营养均衡
